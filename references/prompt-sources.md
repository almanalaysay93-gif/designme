# Prompt Sources — Remotion

Use these repositories as prompt and workflow references for future `designme` projects. Do not copy paid-service assumptions into a build.

## Remotion

- Main repository: https://github.com/remotion-dev/remotion
- Official skills: https://github.com/remotion-dev/skills
- Fundamentals: https://www.remotion.dev/docs/the-fundamentals
- Prompt gallery: https://www.remotion.dev/prompts
- Templates: https://www.remotion.dev/templates
- Curated prompts: https://github.com/quriosity-agent/remotion-prompts

Safe designme use: borrow prompt structures for composition briefs, frame/fps/duration vocabulary, React component decomposition, captions, maps, and prompt-to-video story ideas. Treat Remotion as a normal supporting-sequence specialist under the production contract, never as an automatic replacement for HyperFrames final assembly.

## Free-only boundary

Use only public repository/docs content and local or already-installed tools. Do not call Remotion Lambda, paid APIs, paid model providers, paid voice services, paid asset services, Kie.ai generation, subscriptions, trials, billing-enabled integrations, or credit-consuming services. When a prompt implies one of those services, rewrite it to use local code, FFmpeg, Chromium, Playwright, Python, HyperFrames, or approved user-provided assets.

## Hairline

- Repository: https://github.com/lucasmarkes/hairline
- Skill: https://github.com/lucasmarkes/hairline/tree/main/skills/hairline-create

Use Hairline for pointer-responsive interactive figures, technical diagrams, and self-contained line illustrations. Read its concepts and ten rules before creating a figure. Keep it separate from video rendering, use approved Design DNA tokens, and validate the browser result, accessibility, reduced-motion behavior, rest pose, and tour.

## Anime.js and animated words

Use https://animejs.com/documentation/ and https://github.com/juliangarnier/anime for current v4 APIs, and https://tobiasahlin.com/moving-letters/ for visual inspiration (older code needs migration). Research additional public live examples that fit the actual build. Follow [the research contract](animejs-integration.md) and produce `word-animation-references.md` before motion planning.
