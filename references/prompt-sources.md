# Prompt Sources — Blotato and Remotion

Use these repositories as prompt and workflow references for future `designme` projects. Do not copy their paid-service assumptions into a build.

## Blotato

- Repository: https://github.com/Blotato-Inc/blotato-skills
- Source patterns: content coach, brand brief, post writer, post grader, repurpose, viral hooks, and faceless-video briefing.
- Safe designme use: borrow the intake questions, brand/voice capture, hook frameworks, repurposing matrix, and grading language for video briefs and launch-film copy.
- Not allowed: Blotato publishing/scheduling, paid video generation through Kie.ai or another provider, account actions, external posting, or any paid API.

## Remotion

- Main repository: https://github.com/remotion-dev/remotion
- Official skills: https://github.com/remotion-dev/skills
- Fundamentals: https://www.remotion.dev/docs/the-fundamentals
- Prompt gallery: https://www.remotion.dev/prompts
- Templates: https://www.remotion.dev/templates
- Curated prompts: https://github.com/quriosity-agent/remotion-prompts

Safe designme use: borrow prompt structures for composition briefs, frame/fps/duration vocabulary, React component decomposition, captions, maps, and prompt-to-video story ideas. Treat Remotion as an optional reference or explicitly requested React renderer, never as an automatic replacement for HyperFrames.

## Free-only boundary

Use only public repository/docs content and local or already-installed tools. Do not call Remotion Lambda, paid APIs, paid model providers, paid voice services, paid asset services, Blotato publishing, Kie.ai generation, subscriptions, trials, billing-enabled integrations, or credit-consuming services. When a prompt implies one of those services, rewrite it to use local code, FFmpeg, Chromium, Playwright, Python, HyperFrames, or approved user-provided assets.

## Hairline

- Repository: https://github.com/lucasmarkes/hairline
- Skill: https://github.com/lucasmarkes/hairline/tree/main/skills/hairline-create

Use Hairline for pointer-responsive interactive figures, technical diagrams, and self-contained line illustrations. Read its concepts and ten rules before creating a figure. Keep it separate from video rendering, use approved Design DNA tokens, and validate the browser result, accessibility, reduced-motion behavior, rest pose, and tour.
